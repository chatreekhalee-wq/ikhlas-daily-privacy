# Privacy Policy - Ikhlas Daily Uploader

Last updated: 1 November 2026

Ikhlas Daily Uploader is a private automation tool used only by the owner of the YouTube channel Ikhlas Daily, https://www.youtube.com/@IkhlasDaily, to upload and schedule the channel's own videos. It is not offered to the public.

## Data accessed

With the channel owner's consent, the tool uses the YouTube Data API to upload videos to the owner's channel and to read public video search results and view counts, in order to choose which Quran passages to recite.

## Storage and sharing

The OAuth credentials are stored as encrypted secrets in the owner's private GitHub repository. No personal data of other users is collected, stored, sold or shared with third parties.

## Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, https://developers.google.com/terms/api-services-user-data-policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
